# Bookmark Manager

React + TypeScript + Vite で作成したブックマーク管理アプリです。

https://miya256.github.io/bookmark-manager/

## Features

- ブックマークの追加・削除
- フォルダの作成
- ブックマークやフォルダの名前変更

## Tech Stack

- React
- TypeScript
- Vite

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
